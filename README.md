# きっかけ収集ツール（受付終了）

減税・歳出削減・小さな政府に関心を持った「きっかけ」を匿名で集めるための投稿ツールです。
2026年10月に受付を終了し、バックエンド（Supabase）も削除したため、現在は動作しません。
コードは参考として残しています。

## 構成
- `index.html`：投稿フォーム・投稿一覧・分析タブ（準備中のまま終了）を持つ単一の HTML
- `setup.sql`：Supabase のテーブル作成スクリプト（行レベルセキュリティ、DB 側の個人情報チェック、報告3件で自動非公開にするトリガー）

## 作成について
このツールは Claude（AI）を使って作成しました。
